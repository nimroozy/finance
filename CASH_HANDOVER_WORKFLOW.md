# Cash Handover Workflow

Statuses: `draft` → `submitted` → `approved` | `partially_approved` | `rejected` (or `clarification`).

Variance is recorded when approved amount ≠ selected payment total. Partial approval marks only fully covered payments `handed_over`; remainder items stay visible as `partial` / `not_approved`.

See also: `BRANCH_CASHBOXES.md`, `CASHBOX_TRANSFERS.md`, `CASH_RECONCILIATION.md`, `CUSTODY_REVERSALS.md`.
